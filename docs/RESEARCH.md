## Материал 2: инфраструктура исследований

[Статья Roan](https://x.com/RohOnChain/status/2109650293365305427?s=20), «How to Build the Most Powerful AI Trading System (Hedge Fund Infrastructure)», описывает QuantGPT и слои данных, вычислений и постоянно работающего исполнителя. Полезны доступность данных на момент решения, независимое вычисление результатов, отделённая историческая проверка, журнал и paper до live.

Статья имеет характер продвижения продукта. В её собственных ограничениях указаны результаты без комиссий/проскальзывания и live только для Alpaca, акций и ETF США. Поэтому наличие crypto-данных не доказывает возможность исполнения нашей криптоторговли. Перебор параметров требует защиты от переобучения; успешная проверка на одной отложенной выборке не гарантирует устойчивости. Цены, качество данных, происхождение команды и результаты автора независимо не подтверждены.

## Проверка первичных источников

| Кандидат | Подтверждённое назначение | Вывод для нас |
| --- | --- | --- |
| [TradingAgents](https://github.com/TauricResearch/TradingAgents) | Мультиагентное исследование рынка; README описывает аналитиков, трейдера и менеджеров, исследовательский характер и симулированное исполнение | Источник архитектурных идей. Не считать готовым production-исполнителем |
| [ai-hedge-fund](https://github.com/virattt/ai-hedge-fund) | Proof of concept; README прямо исключает реальные сделки | Источник идей для оркестрации и сравнений. Не подключать к деньгам без собственной системы исполнения |
| [Freqtrade](https://www.freqtrade.io/en/stable/) | Криптобот, backtesting, dry-run, стратегии и управление | Первый кандидат для отдельной проверки пригодности; ещё не принято решение |
| [Hummingbot](https://hummingbot.org/) | Инфраструктура криптоботов и market making | Рассмотреть, если выберем такую торговую задачу; не нужен дополнительно к Freqtrade без причины |

У Freqtrade [REST API](https://www.freqtrade.io/en/stable/rest-api/) содержит внешние команды входа, выхода и остановки покупок. Это делает интеграционный эксперимент возможным, но не подтверждает наши гарантии риска, дедлайна и идемпотентности. API управления рекомендуется держать закрытым от публичного интернета.

У Freqtrade есть [backtesting](https://www.freqtrade.io/en/stable/backtesting/) и [lookahead analysis](https://www.freqtrade.io/en/stable/lookahead-analysis/). Возможность тестировать стратегию не означает, что модель исполнения полностью отражает реальные торги; расходы, ликвидность и задержки нужно оценивать отдельно.

## Наше предложение по итогам

Собрать собственную координацию сессии, компактные контракты данных, независимую политику риска и журнал. Для аналитики использовать роли как в исследовательских системах, адаптированные к крипторынку. Для исполнения проверить один готовый движок; при недостатке контроля написать узкий адаптер.

Не выбирать QuantGPT обязательным фундаментом: сначала проверить пригодность данных и API для конкретной биржи и внутридневного горизонта. MCP можно использовать для исследовательского доступа; быстрый торговый цикл не обязан проходить через чат или MCP.

## Что проверить перед заимствованием

Лицензия конкретного компонента/версии, поддержка выбранной биржи и рынка, лимиты и типы ордеров, внешнее управление, бюджет вызовов, сохранение состояния, история изменений и тестовые режимы. Для оставшихся названий из подборки сначала установить точный репозиторий и официальный статус: одно название не идентифицирует поставщика.

Для стратегии отдельно проверить наличие исторических bid/ask или допущения об их замене, комиссии выбранного аккаунта, пропуски, изменения списка инструментов, минимальные суммы, отсутствие будущих данных, стоимость закрытия по дедлайну и реалистичность fills.
